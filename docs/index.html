Use the same capture files, filters, and packet model in a terminal session or inside your application.

Live capture
Linux socket/ring and macOS BPF backends, kernel timestamps, direction selection, and drop statistics.
Portable capture files
Read and write pcap/pcapng, stream through standard input/output, and rotate files by size or time.
Protocol dissection
Inspect Ethernet, IPv4/IPv6, TCP/UDP, DNS, HTTP/1.x, TLS hellos, and tunneled traffic.
Capture filters
Compile tcpdump-style expressions to classic BPF in Ruby, with the same filter for live traffic and saved files.
Stateful analysis
Follow TCP streams, reassemble application data, and report conversations, endpoints, and traffic intervals.
Ruby integration
Access typed fields and structured diagnostics, export JSON, and register custom protocol dissectors.

require 'redhound'

Redhound.open('trace.pcapng') do |reader|
  reader.each do |packet|
    puts packet.summary
    p packet['ip.src']
  end
end
